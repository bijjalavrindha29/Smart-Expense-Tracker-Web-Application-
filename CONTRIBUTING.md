# Contributing

Thanks for your interest in improving Smart Expense+. To keep contributions efficient and reviewable, follow these guidelines.

- Fork the repository and create a feature branch: `feature/your-short-description`.
- Write clear, focused commits. Use present-tense messages.
- Keep changes small and scoped to a single concern.
- Run linters and tests before opening a PR.
- Include documentation for any public API changes.

Code style

- JavaScript/Node: follow standard ESLint rules — add a config if you extend the project.
- Use descriptive variable and function names; prefer explicitness over cleverness.

Pull requests

- Open a PR against `main` with a short description and testing instructions.
- Link related issues and include screenshots or logs for UI/UX changes.
