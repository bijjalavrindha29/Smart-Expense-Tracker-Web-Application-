# Client — Smart Expense+

Minimal React client used for development and UI prototyping. Extend the components under `src/` to build the dashboard, forms, and charts.

Quick start

```bash
cd client
npm install
npm start
```

Notes

- The client uses `proxy` in `package.json` to forward API requests to the server during development.
- Charts can be implemented using `chart.js` or `react-chartjs-2`.
